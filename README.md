# Tim Rent Car

เว็บบริหารจัดการรถเช่า ใช้ JavaScript, Node.js และ SQLite ครอบคลุมการค้นหารถ การจอง การส่งมอบ การรับคืน และการตรวจสภาพรถ

## ส่วนที่ผมรับผิดชอบ

**รัฐพงศ์ คูสกุลธรรม (Rattapong Koosakultham)**

- ออกแบบหน้าเว็บและการนำเสนอข้อมูลของระบบ
- ทดสอบการทำงานของระบบ
- ใช้ AI ช่วยพัฒนาโครงการและหาแนวทางแก้ปัญหา

## ความสามารถหลัก

- ค้นหารถและตรวจสอบช่วงเวลาว่าง ป้องกันการจองทับซ้อน
- สร้างการจอง คำนวณค่าเช่า ใช้ส่วนลด และจัดทำสัญญา
- สาธิตการชำระเงิน พร้อมสร้างเอกสาร PDF ภาษาไทยและอีเมลในกล่องข้อความทดสอบ (Test Inbox)
- บันทึกการส่งมอบ รับคืน ตรวจสภาพ และงานซ่อมบำรุง
- จัดการผู้ใช้ รถ ราคา และรายงานตามสิทธิ์ของแต่ละบทบาท

ระบบรองรับลูกค้า เจ้าหน้าที่บริการ ผู้ดูแลระบบ และผู้ตรวจสภาพ

## เทคโนโลยี

- **ส่วนหน้าบ้าน:** HTML, CSS, JavaScript
- **ส่วนหลังบ้าน:** Node.js
- **ฐานข้อมูล:** SQLite
- **เอกสารและ QR:** PDFKit, qrcode

## เริ่มใช้งานในเครื่อง

ติดตั้ง Node.js 24 ขึ้นไป ดาวน์โหลดโครงการแล้วเปิดหน้าต่างคำสั่งในโฟลเดอร์หลัก จากนั้นรัน:

```sh
npm ci
npm start
```

บน Windows PowerShell หากเรียก npm ไม่ได้ ให้ใช้ `npm.cmd ci` และ `npm.cmd start`

เปิด [http://127.0.0.1:3003](http://127.0.0.1:3003) ระบบสร้างฐานข้อมูลและข้อมูลสาธิตเมื่อเริ่มใช้งานครั้งแรก หยุดเซิร์ฟเวอร์ด้วย Ctrl+C

บน Windows สามารถใช้ `launchers/windows/Start-Tim-Rent-Car.cmd` เพื่อเปิดระบบพร้อมตัวตรวจสถานะ หรือรัน `npm run start:monitored` แทน `npm start`
